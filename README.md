# SpeedX Coach — Update Host

Public release host for the **SpeedX Coach** desktop app. This repository holds
**only the built installers** (`.dmg` / `.exe` / `.AppImage`) so the app's
auto-updater can fetch them. The application **source code lives in a private
repository** — nothing here is source.

**Download the latest app:** https://github.com/olam-source/speedx-coach-updates/releases/latest
